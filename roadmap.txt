PHASE 2: DATABASE & AUTHENTICATION (The Brain)

Goal: Secure user accounts and define the exact data structures and constraints.

    [ ] Customer Auth: Supabase Email + Google OAuth for buyers.

    [ ] Admin Auth: separate magic-link-only flow with a hardcoded email allowlist. Admin and customer should never share a session shape.

    [ ] Users Table: Map to Auth, define roles (customer, admin).

    [ ] Inventory Table: Create books table with price, type, and real-time inventory_count.

    [ ] Orders Table: Track status (new, packed, shipped), Razorpay IDs, and tracking URLs.

    [ ] Carts Table (NEW): Server-backed cart tied to user_id (logged-in) OR anonymous_session_id (guest). Enables abandoned-cart emails later.

    [ ] Digital Vault: Create access_grants table with a UNIQUE constraint locking user_id + book_id to prevent duplicate access.

    [ ] Coupon Table: Store codes, discount percentages, and type (global vs single_use). Add atomic transaction locks to prevent race conditions on single-use codes.

    [ ] Community Tables: Create content_submissions and feedback tables (no user_id required for frictionless guest submission).

    [ ] Security: Enable Row Level Security (RLS) on all tables. Only Admin can write to inventory/orders.

    [ ] Audio Protection: Build Next.js API route to fetch audio from R2 and pipe/stream it directly to the client (no signed URLs sent to browser).
