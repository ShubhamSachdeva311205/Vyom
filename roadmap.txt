    [ ] P1: Disposable-email bypass — canonicalize Gmail, punycode-normalize domains, reject mixed-script local-parts.

    [ ] P1: Service-role in cart user-facing path — refactor to anon client + RLS via set_config.

    [ ] P1: Sign-in error oracle — collapse all auth errors to one user-facing string.
