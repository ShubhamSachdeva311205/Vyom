PHASE 2: DATABASE & AUTHENTICATION (The Brain)

Goal: Secure user accounts and define the exact data structures and constraints.

    [x] Customer Auth: Supabase Email + Google OAuth for buyers (with disposable-email blocklist).

    [x] Admin Auth: separate magic-link-only flow with a hardcoded email allowlist. Admin and customer share no session shape; gated by middleware.

    [x] Users Table: Map to Auth, define roles (customer, admin). Auto-populated via on_auth_user_created trigger.

    [x] Inventory Table: Books table with price (paise), type, format, GST class, and real-time inventory_count.

    [x] Orders Table: Status enum (pending_payment → packed → shipped → delivered/cancelled/refunded), Razorpay IDs, tracking URLs, GST/tax columns.

    [x] Carts Table: Server-backed cart tied to user_id OR anonymous_session_id. Unique partial indexes + check constraint enforce one cart per owner.

    [x] Digital Vault: access_grants with UNIQUE (user_id, book_id) and source enum (order/amazon/manual/refund_revoked).

    [x] Coupon Table: coupons + coupon_redemptions split. CHECK forces single_use codes to max_uses=1. UNIQUE (coupon_id, user_id) on redemptions enforces one-redemption-per-email.

    [x] Community Tables: content_submissions + feedback, both accept guest submissions (user_id nullable).

    [x] Security: RLS enabled on all 11 tables. is_admin() helper function for policy checks. Anonymous cart access scoped via current_setting('app.anonymous_session_id').
