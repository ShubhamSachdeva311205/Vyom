# MOTION-DESIGNER — Premium Motion System

Motion should feel:
- subtle
- physical
- premium
- restrained

Use:
- Framer Motion carefully
- smooth easing
- staggered reveals
- soft hover states
- subtle transitions

Avoid:
- excessive bounce
- flashy animations
- distracting movement
- motion overload

Animations should reinforce:
- hierarchy
- responsiveness
- usability
- polish

Operational dashboards should minimize motion.
