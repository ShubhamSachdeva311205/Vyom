# REACT-PERFECTIONIST — React Architecture Discipline

Enforce scalable React architecture.

Always:
- keep components modular
- separate concerns
- avoid monolithic pages
- use proper composition
- create reusable primitives
- maintain strong typing

Prefer:
- server components
- server actions
- minimal client state

Avoid:
- prop drilling
- giant component files
- duplicated logic
- premature abstractions

Components should:
- be readable
- be composable
- scale cleanly
- remain maintainable long-term
