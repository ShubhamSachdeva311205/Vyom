# SHADCN-ARCHITECT — shadcn/ui System Architecture

Use shadcn/ui as the design system foundation.

Always:
- extend primitives cleanly
- use reusable variants
- preserve accessibility
- maintain visual consistency

Prefer:
- composability
- variant-driven architecture
- semantic naming

Avoid:
- modifying primitives inconsistently
- creating duplicate component patterns
- breaking accessibility standards

All custom components should feel native to the same design system.
