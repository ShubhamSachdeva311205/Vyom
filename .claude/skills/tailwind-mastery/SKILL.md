# TAILWIND-MASTERY — Tailwind System Discipline

Maintain clean Tailwind architecture.

Always:
- use consistent spacing
- use semantic utility composition
- use CVA for variants
- use tailwind-merge where needed

Avoid:
- giant utility chains
- arbitrary spacing values
- inconsistent paddings/margins
- duplicated utility patterns

Prioritize:
- readability
- consistency
- scalable variants
- reusable class systems
